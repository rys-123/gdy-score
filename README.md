> 专为“干瞪眼”扑克牌游戏打造的工业级移动端计分助手。告别纸笔，智能计算，一键结算！

## 📖 项目简介

这是一个**移动端优先 (Mobile-First)** 的 PWA Web 应用。它解决了干瞪眼游戏线下计分繁琐、算分易错、找不到纸笔的痛点。
采用极简的现代化 UI 设计，支持**自动规则判定**、**炸弹翻倍计算**、**断网离线使用**，是牌桌上的必备神器。

## ✨ 功能特点

*   **📱 极致体验**：专为手机竖屏优化，操作丝滑，支持 iOS/Android 添加到主屏幕（伪原生 App 体验）。
*   **🤖 智能辅助**：
    *   **自动春天判定**：输入剩余牌数 ≥5 张时，自动标记为“春天”（支持手动修正）。
    *   **输入校验**：自动限制牌数范围（0-6张），防止输入错误。
*   **⚡️ 高效录入**：
    *   赢家（剩0张）无需输入，留空即可。
    *   列表式输入，多人对局也能一目了然。
*   **💣 复杂算分**：内置炸弹翻倍、春天翻倍公式，自动计算正负分。
*   **🏆 终局仪式感**：
    *   实时排行榜，动态皇冠标识。
    *   **最终结算页面**：自动统计总分，直观展示排名。
*   **💾 数据安全**：基于 LocalStorage 本地存储，刷新页面数据不丢失，随时可恢复对局。

## 🚀 如何安装 (推荐)

本项目支持 **PWA (Progressive Web App)** 技术，无需下载安装包，直接添加至桌面即可秒开。

### 🍎 iOS (iPhone/iPad)
1. 使用 **Safari 浏览器** 打开：[应用链接](https://rys-123.github.io/gdy-score/)
2. 点击底部中间的 **“分享”** 按钮 (带箭头的方框)。
3. 上滑找到并点击 **“添加到主屏幕”**。
4. 点击右上角 **“添加”**，桌面即可看到应用图标。

### 🤖 Android (安卓)
1. 使用 **Chrome 浏览器** 打开链接。
2. 点击右上角菜单 (三个点)。
3. 选择 **“安装应用”** 或 **“添加到主屏幕”**。

## 🕹️ 操作指南

1.  **添加玩家**：点击顶部“管理”按钮，输入名字添加玩家（支持重名检测，最多6字）。
2.  **本局录入**：
    *   **赢家**：手里剩 0 张牌，输入框**不填（留空）**即可。
    *   **输家**：输入剩余牌数（如 1-5）。
    *   **春天**：若输家未出牌（系统检测牌数≥5自动勾选），图标变绿 🌱 即为被春天。
3.  **炸弹设置**：在底部调整本局出现的炸弹总数，分数将按 $2^N$ 翻倍。
4.  **结算**：点击“确认结算”，系统自动计算分数并更新排行榜。
5.  **终局**：游戏结束后，点击底部的“最终结算”，查看排名。

## 📏 计分规则说明

本应用严格遵循常见的干瞪眼玩法逻辑：

1.  **基础分**：等于玩家手中的剩余牌数。
2.  **牌数限制**：
    *   每局每人抓牌 5 张。
    *   **庄家/先出牌者** 多抓 1 张（共 6 张）。
    *   因此，输入限制为 0-6 张，且每局最多只有 1 人可能剩 6 张。
3.  **翻倍规则**：
    *   **春天 (Spring)**：输家一张牌未出，该玩家扣分 × 2。
    *   **炸弹 (Bomb)**：本局每出现 1 个炸弹，**所有**输家扣分 × 2。
4.  **计算公式**：
    $$ 输分 = 剩余牌数 \times 2^{炸弹总数} \times (是否春天 ? 2 : 1) $$
    $$ 赢家得分 = \sum (所有输家扣分绝对值) $$
